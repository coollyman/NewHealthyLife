## 修复：早睡/早起启用后页面不退出 + 任务重复生成

**现象**：在编辑页开启「早睡」或「早起」任务，点"完成"后页面不返回，但首页已出现该任务条目。

**根因**：`HomeStore.enableTask()` 在创建任务快照（写入 DB + 刷新首页 UI）之后，对 TIME 类型任务会 `await requestNotificationPermission()` → `notificationManager.requestEnableNotification()`。该调用弹出系统权限弹窗，`await` 永久阻塞，导致 `enableTask` 不返回 → `EditTaskPage.onComplete` 后续的 `router.back()` 不执行。其他 4 个任务（isAlertEnabled=false）不走这条路径，无此问题。

**修复**：
1. `HomeStore.enableTask`：将提醒设置（权限请求 + createOrUpdateReminder）改为 fire-and-forget（`.catch()` 兜底），不阻塞主流程。卡片更新提前到提醒设置之前。
2. 抽出 `setupReminder(taskId)` 私有异步方法，独立处理权限+闹钟，内部 try-catch 包裹。
3. `EditTaskPage.onComplete`：加 try-finally，保证 `router.back()` 必执行。

**构建验证**：hvigorw BUILD SUCCESSFUL（C 盘 SDK 路径：`C:/Program Files/Huawei/DevEco Studio/sdk`）。
