一、项目概述

开发背景与目标

健康习惯的养成依赖于持续的记录与正向反馈。本项目旨在开发一款运行于 HarmonyOS 平台的健康习惯管理应用， 帮助用户配置和跟踪每日健康习惯（如早起、喝水、跑步等），通过连续打卡、成就徽章、周复盘等激励机制提升用户坚持动力， 并提供个人资料管理和数据清除等完整的应用功能。

  • 支持 7 个预设健康习惯：早起、喝水、吃苹果、每日微笑、刷牙、早睡、跑步
  • 支持用户自定义习惯，可配置名称、图标、目标类型、单位、步进值和执行星期
  • 提供连续打卡天数、成就徽章、周复盘等长期激励手段
  • 包含补救机制、智能目标建议、服务卡片等增强功能

技术栈与工程结构

项目采用 HarmonyOS ArkTS 声明式 UI 框架开发，单模块 entry 承载全部代码。 按职责划分为页面层（pages/components）、状态管理层（viewmodel）、领域规则层（domain/rules）、 服务层（services）和数据持久化层（data），形成清晰的分层架构。

二、功能完成情况

1. 首页与每日打卡

首页是用户的核心操作入口，展示当天目标进度、周日历、任务列表和底部导航。 用户点击任务卡片打开打卡弹窗，根据任务类型完成打卡操作。

  • 顶部展示当天总体完成百分比和连续打卡天数
  • 周日历显示近三周日期和完成状态，支持点击切换查看日期
  • 任务列表展示每个任务的名称、图标、进度条和完成状态
  • 底部导航切换首页、成就页和我的页面

2. 打卡弹窗与撤销机制

打卡弹窗根据任务类型展示不同的进度信息和操作按钮。 数值类任务（如喝水、跑步）按步进值累加，多次打卡后达到目标完成； 一次性任务（如早起、早睡）一次打卡即完成。已完成的任务可撤销最近一次打卡。

  • 数值任务：每次打卡增加一个步进值，达到目标后标记完成
  • 一次性/时间任务：一次打卡直接完成
  • 完成后按钮显示"已完成"，不可重复打卡
  • 弹窗底部提供"撤销打卡"入口，数值任务回退一个步进值

3. 预设习惯与添加任务

添加任务页展示 7 个预设健康习惯的开启状态，用户可直接切换开关启用或停用任务。 页面顶部提供"创建自定义习惯"入口，引导用户进入自定义表单。

  • 预设习惯覆盖作息（早起、早睡）、饮食（喝水、吃苹果）、卫生（刷牙）、情绪（微笑）、运动（跑步）
  • 任务名称通过统一的元数据解析函数获取，预设任务和自定义任务使用相同接口
  • 服务卡片同步显示任务名称和完成状态

4. 自定义习惯创建

自定义习惯功能允许用户创建个性化健康目标。表单包含名称输入、图标选择、目标类型选择 （是否完成 / 次数数值 / 时间目标）、目标值、单位、步进值和执行星期配置。 创建时进行输入校验，防止空值、非法格式和零值。

  • 自定义任务 ID 从 100 开始，与预设任务（0-6）分离
  • 支持 12 个内置图标选择（运动、饮食、作息、学习等分类）
  • 执行星期支持每天、指定星期或自定义组合
  • 校验逻辑覆盖时间格式（HH:mm）、数值合法性、步进值正数

5. 任务编辑与提醒配置

编辑任务页支持修改目标值和提醒设置。预设任务可编辑目标值和提醒开关； 自定义任务可完整编辑名称、图标、类型、目标、单位、步进和执行星期， 并支持软删除（归档后从列表移除但保留历史记录）。

  • 数值型任务支持从预设范围选择目标值（如跑步 1/2/3/5 公里）
  • 提醒服务根据时间和星期频率生成定时提醒
  • 自定义任务归档时取消提醒、移除未完成的今日快照
  • 提供智能目标建议，根据近 7 天完成情况推荐调整目标

6. 月历热力图与历史回顾

月视图以整月日历形式展示完成状态，用不同颜色标识全部完成、部分完成、未完成和无记录四种状态。 支持月份切换，点击日期可回到首页查看当天详情。补救状态以特殊样式标识。

  • 四种状态标识：全部完成（蓝色实心）、部分完成（橙色）、未完成（红色）、无记录（灰色空心）
  • 打卡、启用/停用任务、修改目标后自动同步月视图状态
  • 补救日以蓝色描边标识，区别于正常完成

7. 成就系统与周复盘

成就页展示连续打卡天数、最高连续天数、本周复盘和成就徽章。 连续天数阈值分为 3/7/30/50/73/99 天六级，达标时弹出解锁动画。 周复盘汇总本周完成率、最稳定任务和最易遗漏任务，并给出调整建议。

  • 连续天数规则：当天全部完成 +1，未完成归零（补救可保持连续）
  • 徽章覆盖连续 3/7/30/50/73/99 天目标，解锁时弹窗提示
  • 周复盘统计 7 天完成率、按任务分析稳定性和遗漏情况
  • 用户等级 LV.1-LV.7 根据最高连续天数动态计算

8. 补救机制

补救机制为用户提供了容错能力。当天完成率达到 70% 但未全部完成时，可使用每周一次的补救机会， 保持连续天数不中断。首页在满足条件时显示补救提示卡片，用户确认后生效。

  • 触发条件：当天完成率 ≥ 70% 且未全部完成
  • 频率限制：每自然周（周一至周日）仅可使用一次
  • 效果：连续天数不中断，但当日不计为满分完成
  • 月视图以特殊样式标识补救日

9. 个人资料与用户等级

我的页面展示用户头像、昵称、性别、年龄摘要和动态等级。 等级根据最高连续打卡天数计算（LV.1-LV.7），体现用户坚持程度。 点击用户卡进入资料编辑页，可修改头像、昵称、性别、出生日期、身高和体重。

  • 头像支持从相册选择，昵称支持内联输入
  • 性别以 chip 方式行内选择，出生日期使用 DatePicker
  • 身高和体重旁显示单位（cm / kg）
  • 底部提供"清除所有数据"入口，带二次确认弹窗

10. 数据清除与状态重置

"我的"页面底部提供"清除所有数据"功能。确认后清空所有打卡记录、连续天数、个人资料和自定义任务， 取消已设置的提醒，重新初始化默认任务和今日数据。清除后首页恢复初始状态。

  • 清空 RDB 业务表（dayTaskInfo / dayInfo / recoveryInfo / taskInfo）
  • 清空 Preferences（连续天数状态 + 个人资料）
  • 取消所有已设置的提醒闹钟
  • 重新插入 7 个预设任务（全部关闭状态）

三、技术架构

项目采用五层分层架构，各层职责清晰、单向依赖。业务规则以纯函数形式实现， 不依赖 HarmonyOS 运行时，可独立进行单元测试。UI 层通过 ViewModel 访问领域层和服务层， 数据读写由 Repository 层封装。

Pages / Components 首页、添加/编辑任务、成就、我的、资料编辑页；打卡弹窗、成就弹窗、目标建议卡片等组件
ViewModel / Store HomeStore 管理任务状态、打卡、连续天数、补救、月视图；ProfileStore 管理个人资料
Domain Rules TaskRules（打卡/撤销）、ConsecutiveDaysRules（连续天数）、RecoveryRules（补救）、AchievementRules、WeeklyReviewRules 等
Services ReminderService（提醒调度）、FormService（服务卡片更新）
Repository TaskInfoRepository、DayInfoRepository、DayTaskRepository、RecoveryRepository、PreferencesRepository、ProfileRepository

任务规则与打卡逻辑

任务完成逻辑由 TaskRules 纯函数处理，支持三种任务类型，打卡和撤销均为不可变操作（返回新对象）。

  • ONCE（一次性）：一次打卡即完成，撤销重置为未完成
  • VALUE（数值型）：按 step 累加，达到目标标记完成，撤销回退一个 step
  • TIME（时间型）：一次打卡即完成，同 ONCE

连续天数与成就规则

连续天数状态由 ConsecutiveDaysRules 管理，支持完成计数、撤销回退、跨天检查和补救保持。

  • 当天全部完成 +1 天，未完成归零（补救可保持）
  • 成就阈值 3/7/30/50/73/99 天，达标时弹出解锁弹窗
  • 补救日不中断连续天数，但不计为满分完成

数据持久化

使用 RelationalStore（RDB）存储任务配置、每日进度和打卡记录，Preferences 存储连续天数状态和个人资料。

  • 5 张 RDB 表：taskInfo / dayInfo / dayTaskInfo / formInfo / recoveryInfo
  • 支持 Schema 迁移：ALTER TABLE 自动补充新列
  • 自定义任务与预设任务 ID 分离（0-6 / 100+）

服务卡片与提醒

通过 FormKit 实现桌面服务卡片，展示今日完成进度。提醒服务基于 ReminderAgent 按时间和星期频率调度。

  • 服务卡片支持进度卡片和任务列表卡片两种形态
  • 打卡后自动同步更新所有已添加的服务卡片
  • 提醒支持时间触发和星期频率配置

六、项目亮点

完整的功能闭环

从习惯配置、每日打卡、历史回顾到成就激励，形成完整的健康习惯管理流程，非单纯的功能堆砌。

七、总结与展望

NewHealthyLife 已完成一个健康习惯管理应用的主要功能闭环。用户可以配置预设或自定义习惯， 在首页完成每日打卡，通过月视图回顾历史状态，在成就页获得长期反馈，使用补救机制保持连续， 并在个人中心维护资料信息和清除数据。项目采用分层架构，业务规则以纯函数实现， 配备 277 个单元测试用例覆盖核心逻辑。

后续可进一步优化方向包括：数据趋势图表、任务模板库、深色模式完整适配、 云端数据同步、健康传感器数据联动、桌面快捷打卡小组件等。 当前版本已具备完整的课程项目展示价值，体现了 HarmonyOS 应用开发中的 页面构建、状态管理、数据持久化、领域规则设计和服务集成能力。
