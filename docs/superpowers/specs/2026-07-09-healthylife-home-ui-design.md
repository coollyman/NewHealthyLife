# HealthyLife 首页视觉还原设计

目标：把首页从“功能验收态”的规整表单感，调整为更接近官方 Codelab 的轻快健康生活风格。

范围：
- 顶部进度区：标题和进度左对齐，扩大百分比，保留运动插画背景的主体感。
- 周历卡片：上移叠到顶部背景，缩小箭头干扰，保持白色圆角卡片和七天进度图标。
- 任务列表：标题更有重量，任务卡更宽更高，使用卡片图标资源，弱化表单行感。
- 首页添加按钮：尺寸贴近官方截图，悬停在任务列表和底部 Tab 之间。

不改动：
- 数据库、任务开关、打卡规则、路由和提醒逻辑。
- 添加任务页、编辑任务页的业务流程。

验收：
- `hvigor assembleApp --no-daemon --stacktrace` 编译通过。
- 首页视觉不再呈现居中大标题和普通白色表单行的“乖”感，整体更接近官方 Codelab 首页参考图。
