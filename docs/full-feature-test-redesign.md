# NewHealthyLife 全功能测试重新设计

## 结论

当前测试应拆成三层：

1. 自动设备验证：每次改动先跑构建和 ohosTest，覆盖数据表、仓储、持久化、提醒、安全规则和一次完整启用打卡流程。
2. 自动 UI smoke：每次回归跑脚本，覆盖启动、首页、添加任务页、成就页、我的页，并保存截图和布局文件。
3. DevEco Testing 手工录制与遍历：覆盖复杂输入、日期切换、自定义习惯、个人资料、提醒权限、杀进程重启后的持久化。

## 每次回归必跑

```powershell
devecocli device list
devecocli build
powershell -ExecutionPolicy Bypass -File scripts/run-ohos-test.ps1 -Device 127.0.0.1:5555
powershell -ExecutionPolicy Bypass -File scripts/run-ui-smoke.ps1 -Device 127.0.0.1:5555 -SkipBuild
devecocli log --device 127.0.0.1:5555 --level E --tail 200
```

UI smoke 产物在 `artifacts/ui-smoke`，包括每个关键页面的 `.png` 截图和 `.json` 布局。

## 自动化覆盖范围

自动设备测试已经覆盖：

- 默认 7 个任务初始化、幂等初始化、任务配置保存。
- DayInfo、DayTask、Preferences 的增删改查和重启恢复。
- 启用任务、打卡、完成状态、连续天数、成就解锁规则。
- 数值任务、一次性任务、时间任务的打卡规则和重复打卡边界。
- 自定义习惯 ID、展示元数据、星期过滤、归档语义。
- 月视图日期计算、跨月边界、历史记录读取。
- 个人资料保存、重载、输入校验、摘要展示格式。
- 提醒配置 intent 构建、无效时间过滤、跑步提醒频率解析。
- 周复盘、补签、用户等级和回归 bug 扫描。

自动 UI smoke 已覆盖：

- 应用启动并进入首页。
- 底部 Tab 点击：首页、成就、我的。
- 首页核心文案：健康生活、任务列表。
- 添加任务页打开与返回：添加任务、创建自定义习惯。
- 我的页入口：我的、个人资料。
- 每一步截图和布局留证，便于失败时定位页面。

## DevEco Testing 录制脚本设计

建议录制 4 条脚本，而不是一条超长脚本：

1. `main-flow`：干净安装 -> 启用喝水/苹果/微笑/刷牙/跑步 -> 返回首页逐个打卡 -> 查看成就。
2. `custom-task-flow`：创建是否完成、数值、时间三类自定义习惯 -> 验证首页展示 -> 删除自定义习惯。
3. `date-calendar-flow`：周视图左右切换 -> 过去日期只读 -> 月视图上一月/下一月 -> 点击日期返回首页。
4. `profile-reminder-persistence-flow`：编辑个人资料 -> 编辑跑步提醒 -> 杀进程重启 -> 验证资料和提醒仍存在。

## 手工重点检查

- 过去日期不能打卡，未来日期不能写入真实数据。
- 数值任务达到目标后不应异常重复增加今日进度。
- 跑步打卡弹窗应显示专属背景。
- 空名称、空星期、非法身高体重、非法昵称必须有提示。
- 提醒权限弹窗出现时选择允许后，保存配置并重新进入仍应存在。
- 完成当天全部任务后，连续天数、最高连续天数、徽章和周复盘展示应同步更新。
- 杀掉应用重启后，任务开关、自定义习惯、资料、今日打卡、提醒配置都应恢复。

## 通过标准

- 构建成功。
- ohosTest 失败数为 0。
- UI smoke 成功生成 5 组截图和布局文件。
- DevEco Testing 报告无 Crash、白屏、卡死、无法返回页面。
- 失败时能拿到截图、布局文件、日志和具体操作路径。
